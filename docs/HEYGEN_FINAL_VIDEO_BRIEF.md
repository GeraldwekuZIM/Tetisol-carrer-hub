## Paste This Prompt Into HeyGen

Create a polished 3 to 4 minute professional product presentation video for a software project called Tetisol Career Hub.

Use the uploaded PowerPoint deck as the base structure. Use the Canva deck link as a visual reference. Use the uploaded screenshots and screen recording as real product evidence throughout the video.

The audience is project reviewers, educators, internship coordinators, and technical stakeholders. The tone must be clear, confident, practical, and credible. Avoid exaggerated marketing language. The goal is to explain what the product does, show that it works, and make the MVP feel complete and demo-ready.

Visual style:

- 16:9 business presentation video.
- Clean digital product walkthrough style.
- Use screenshots in browser-style frames.
- Use the MP4 recording for short motion cutaways.
- Use subtle zooms and pans on screenshots.
- Keep captions short.
- Make the actual product UI visible and readable.
- Use low-volume professional background music, but keep the voiceover dominant.

Scene plan:

1. Opening: use the landing page hero screenshot. Show the product name Tetisol Career Hub and the caption "Learn. Certify. Apply."
2. Problem: explain that learning progress, certificates, internships, applications, and CV writing are usually fragmented.
3. Product overview: use landing page, course categories, auth, and course catalog screenshots to show the public product and entry flow.
4. Learner dashboard: use the dashboard screenshots to show readiness, reminders, learning momentum, certificates, applications, and AI coach guidance.
5. Learning experience: use course catalog, course cards, my learning, course player, and quiz screenshots. Explain course enrollment, lessons, notes, progress, quizzes, and certificates.
6. Certificates and CV: use certificate library, CV builder, and profile editor screenshots. Explain that completed learning can become visible career proof.
7. Internship workflow: use internship discovery, internship detail, saved roles, and internship cards. Explain match scores, match reasons, saved roles, and opportunity shortlist.
8. Application tracker: use the Kanban board screenshot. Explain the statuses: interested, applied, interview, offer, and rejected.
9. Admin workspace: use admin dashboard, course management, internship management, analytics overview, analytics charts, and course analytics screenshots. Explain that admin users can manage content and monitor learner readiness.
10. Technical foundation: show a simple text slide summarizing Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, shadcn, Base UI, lucide-react, localStorage demo persistence, and Supabase auth/schema scaffolding.
11. Closing: return to the landing page or dashboard. End with the caption "Tetisol Career Hub: learning connected to employability."

Voiceover script:

Tetisol Career Hub is a demo-ready MVP built to connect practical technology learning with internship readiness. The platform helps learners discover courses, complete lessons, earn certificates, find internships, track applications, and strengthen their CV from one connected workspace.

Many learners complete courses but struggle to turn that progress into a clear career story. Certificates, projects, internship searches, application notes, and CV updates are often scattered across different tools. Tetisol Career Hub brings those pieces together.

The product includes a public landing page, course catalog, authentication, a student workspace, and an admin workspace. Students can move through onboarding, learning, certificates, internships, saved roles, applications, CV building, and profile management. Admin users manage content and analytics.

The learner dashboard acts as a command center. It brings together readiness, reminders, active learning, certificates, applications, recommended opportunities, and AI career guidance so the learner always knows what to do next.

The learning experience is structured around practical employability tracks. Learners can browse courses, enroll, complete lessons, save notes, take quizzes, and build measurable progress. Completion can unlock certificates and feed into the learner profile.

Tetisol turns learning proof into career proof. Certificates, completed courses, projects, skills, and achievements can be reflected in the CV builder, where learners also receive scoring and suggestions to strengthen their employability story.

The career workflow connects learning to real opportunities. Internship recommendations are ranked using the learner's skills, interests, course history, certificates, saved roles, and preferences. Learners can save roles, review match reasons, and move opportunities into the application tracker.

The application tracker keeps the internship process organized. Opportunities move through interested, applied, interview, offer, and rejected stages, with notes and deadlines kept visible in one place.

The admin workspace supports the teams behind the platform. Admin users can manage courses, modules, lessons, quizzes, internships, and content status. Analytics surface learner activity, completion, certificates, readiness, risk, difficult modules, and suggested instructor actions.

Technically, Tetisol Career Hub is built with Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, shadcn, Base UI, and lucide-react. The app runs as a full local demo with seeded data in localStorage and includes Supabase authentication entry points, schema, seed data, row-level security policies, and storage scaffolding.

The implemented MVP includes the full local demo experience, student learning and career flows, admin content flows, analytics, a route-aware copilot, Supabase auth entry points, and database schema. Future-ready work includes full Supabase persistence, server-side session protection, generated certificate files, public verification, storage-backed assets, and live LLM-backed copilot responses.

Tetisol Career Hub is more than a course catalog. It is a connected workflow for helping learners move from skill-building to visible career readiness, with the tools to learn, prove progress, find opportunities, and manage the path toward internships.
