## Full Voiceover Script

Use this script for AI text-to-speech or narration. Keep pacing steady and professional.

Tetisol Career Hub is a demo-ready MVP built to connect practical technology learning with internship readiness. The platform helps learners discover courses, complete lessons, earn certificates, find internships, track applications, and strengthen their CV from one connected workspace.

Many learners complete courses but struggle to turn that progress into a clear career story. Certificates, projects, internship searches, application notes, and CV updates are often scattered across different tools. Tetisol Career Hub brings those pieces together.

The product starts with a public landing page and course discovery experience. Learners can explore practical categories such as Artificial Intelligence, Prompt Engineering, Cybersecurity, Web Development, Data Analytics, and Career Readiness. The goal is not just to list courses, but to connect learning paths to employability outcomes.

The app includes authentication and a local demo mode with seeded student and admin accounts. This makes the MVP easy to present and test without needing full backend setup, while still keeping the product structure ready for real authentication.

Once a learner signs in, the dashboard becomes their command center. It brings together readiness, learning momentum, certificates, applications, reminders, recommended opportunities, and AI career guidance so the learner always has a clear next step.

The learning workspace is structured around practical employability tracks. Learners can view enrolled courses, continue lessons, save notes, track progress, and complete quizzes. Learning is not isolated from the rest of the product. It feeds recommendations, certificates, CV content, and career readiness signals.

Certificates and CV building turn learning proof into career proof. The certificate area shows completed learning achievements, while the CV builder helps learners organize their summary, skills, projects, certifications, achievements, and experience. The app also provides CV scoring and guidance to help learners improve their employability story.

The internship workflow connects learners to real opportunities. Internship recommendations are ranked using the learner's skills, interests, course history, certificates, saved roles, and preferences. Learners can review match reasons, save roles, and build a shortlist of opportunities that fit their direction.

The application tracker keeps the internship process organized. Opportunities move through interested, applied, interview, offer, and rejected stages, with notes and deadlines kept visible in one place.

The admin workspace supports the teams behind the platform. Admin users can manage courses, modules, lessons, quizzes, internships, and content status. This gives the product an internal operations layer, not just a student-facing experience.

Admin analytics help instructors and coordinators understand learner progress. The analytics views surface engagement, completion, certificates, readiness, risk, difficult modules, and internship-ready learners. This helps teams identify where support is needed.

Technically, Tetisol Career Hub is built with Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, shadcn, Base UI, and lucide-react. The app runs as a full local demo with seeded data in localStorage and includes Supabase authentication entry points, database schema, seed data, row-level security policies, and storage scaffolding.

The implemented MVP includes the full local demo experience, student learning and career flows, admin content flows, analytics, a route-aware copilot, Supabase auth entry points, and database schema. Future-ready work includes full Supabase persistence, server-side session protection, certificate file generation, public verification, storage-backed assets, and live LLM-backed copilot responses.

Tetisol Career Hub is more than a course catalog. It is a connected workflow for helping learners move from skill-building to visible career readiness, with the tools to learn, prove progress, find opportunities, and manage the path toward internships.
