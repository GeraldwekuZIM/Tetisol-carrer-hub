Voiceover script:

Tetisol Career Hub is a demo-ready MVP built to connect practical technology learning with internship readiness. The platform helps learners discover courses, complete lessons, earn certificates, find internships, track applications, and strengthen their CV from one connected workspace.

Many learners complete courses but struggle to turn that progress into a clear career story. Certificates, projects, internship searches, application notes, and CV updates are often scattered across different tools. Tetisol Career Hub brings those pieces together.

The product includes a public landing page, course catalog, authentication, a student workspace, and an admin workspace. Students can move through onboarding, learning, certificates, internships, saved roles, applications, CV building, and profile management. Admin users manage content and analytics.

The learner journey starts with a profile. From there, Tetisol recommends relevant courses and opportunities. As the learner enrolls, completes lessons, saves notes, takes quizzes, and earns certificates, their activity feeds readiness signals, reminders, recommendations, and CV content.

The career workflow connects learning to real opportunities. Internship recommendations are ranked using the learner's skills, interests, course history, certificates, saved roles, and preferences. Learners can save roles, review match reasons, and move opportunities into an application tracker.

Tetisol turns learning proof into career proof. The CV builder includes profile summary, education, skills, experience, projects, certifications, and achievements. Completed courses and certificates can be imported into the CV, while scoring and suggestions help the learner improve their employability story.

The admin workspace supports the teams behind the platform. Admin users can manage courses, modules, lessons, quizzes, internships, and content status. Analytics surface learner activity, completion, certificates, readiness, risk, difficult modules, and suggested instructor actions.

Technically, Tetisol Career Hub is built with Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, shadcn, Base UI, and lucide-react. The app runs as a full local demo with seeded data in localStorage and includes Supabase authentication entry points, schema, seed data, row-level security policies, and storage scaffolding.

For the demo, start at the landing page, then sign in as demo@tetisol.com with the password careerhub to show the student experience. To show the admin tools, sign in as admin@tetisol.com using the same password.

The implemented MVP includes the full local demo experience, student learning and career flows, admin content flows, analytics, a route-aware copilot, Supabase auth entry points, and database schema. The next steps are full Supabase persistence, stronger server-side session protection, generated certificate files, public verification, storage-backed assets, and live LLM-backed copilot responses.

Tetisol Career Hub is more than a course catalog. It is a connected workflow for helping learners move from skill-building to visible career readiness, with the tools to learn, prove progress, find opportunities, and manage the path toward internships.
