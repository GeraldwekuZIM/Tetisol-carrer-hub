# Tetisol Career Hub Video Presentation

## Format

- Target length: 3 to 4 minutes
- Audience: project reviewers, partners, educators, internship coordinators, and technical stakeholders
- Tone: professional, clear, product-led
- Visual style: modern software demo with screen recordings, concise captions, and light motion between sections

## Core Message

Tetisol Career Hub connects practical technology learning with internship readiness. It gives learners one workspace to discover courses, complete lessons, earn certificates, find internships, track applications, and strengthen their CV, while giving admins tools to manage content and monitor learner progress.

## Video Script

### 1. Opening

Visuals:

- Start on the Tetisol Career Hub landing page.
- Show the hero section, course categories, and dashboard preview.

Voiceover:

Tetisol Career Hub is a demo-ready MVP built to connect learning, proof, and employability. Instead of treating courses, certificates, internships, applications, and CV writing as separate tasks, the platform brings them into one connected student workspace.

On-screen caption:

Learn. Certify. Apply.

### 2. The Problem

Visuals:

- Show quick cuts of course discovery, certificate cards, internships, applications, and CV builder.
- Use simple text overlays to show fragmented workflows.

Voiceover:

Many learners complete courses but struggle to turn that progress into a clear career story. Their certificates, projects, internship searches, application notes, and CV updates often live in different places. Tetisol Career Hub solves this by making learning activity feed directly into career readiness.

On-screen caption:

From fragmented progress to connected readiness.

### 3. Student Dashboard

Visuals:

- Sign in with `demo@tetisol.com`.
- Open `/dashboard`.
- Highlight readiness score, AI coach panel, next best action, certificates, reminders, and internship signals.

Voiceover:

The student dashboard acts as a command center. It brings together learning momentum, upcoming deadlines, certificates, CV quality, recommended opportunities, and a route-aware copilot that guides the learner based on where they are in the product.

On-screen caption:

A command center for learner progress.

### 4. Learning Flow

Visuals:

- Open `/courses`, then a course detail page.
- Show enrollment, modules, skills, outcomes, and certificate availability.
- Open `/learning` and `/learning/[slug]`.
- Show lesson content, notes, progress, and quiz flow.

Voiceover:

Courses are structured as practical employability tracks. Learners can browse by category, enroll, complete lessons, save notes, take quizzes, and build measurable progress. Completion can unlock certificates and feed into the learner profile.

On-screen caption:

Courses connected to outcomes.

### 5. Certificates And CV

Visuals:

- Open `/certificates`.
- Show a certificate preview.
- Open `/cv-builder`.
- Show CV sections, score, suggestions, and learning import.

Voiceover:

Tetisol turns learning proof into a stronger employability story. Certificates, completed courses, projects, skills, and achievements can be imported into the CV builder, where learners also receive scoring and suggestions to improve their profile.

On-screen caption:

Learning proof becomes career proof.

### 6. Internship Discovery

Visuals:

- Open `/internships`.
- Show personalized match scores and match reasons.
- Save an internship.
- Open an internship detail page and add it to the tracker.

Voiceover:

The internship area recommends opportunities based on the learner's profile, skills, interests, learning history, certificates, saved roles, and preferences. This helps learners focus on roles that match what they are actually building.

On-screen caption:

Recommended opportunities, not random listings.

### 7. Application Tracker

Visuals:

- Open `/applications`.
- Show the Kanban pipeline.
- Move an opportunity across statuses.
- Show deadline and notes editing.

Voiceover:

Once a learner starts applying, the application tracker keeps the process organized. Opportunities move through interested, applied, interview, offer, and rejected stages, with deadlines and notes kept visible in one place.

On-screen caption:

Track every application clearly.

### 8. Admin Workspace

Visuals:

- Sign in with `admin@tetisol.com`.
- Open `/admin`.
- Show course management, internship management, platform analytics, course analytics, and student analytics.

Voiceover:

The admin workspace supports the teams behind the platform. Admin users can manage courses and internships, review learner readiness, inspect course performance, and identify students who may need support.

On-screen caption:

Admin tools for content and learner insight.

### 9. Technical Foundation

Visuals:

- Show a clean project structure graphic or quick code editor shots.
- Show `app/`, `components/`, `lib/`, `services/`, `supabase/`, and `types/`.

Voiceover:

Technically, the project is built with Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, shadcn, Base UI, and lucide-react. It runs as a complete local demo using seeded state in localStorage, while also including Supabase authentication entry points, schema, seed data, row-level security policies, and storage scaffolding for future persistence.

On-screen caption:

Demo-ready now. Backend-ready next.

### 10. Closing

Visuals:

- Return to the dashboard or landing dashboard preview.
- End on the Tetisol Career Hub name and core value proposition.

Voiceover:

Tetisol Career Hub is more than a course catalog. It is a connected workflow for helping learners move from skill-building to visible career readiness, with the tools to learn, prove progress, find opportunities, and manage the path toward internships.

On-screen caption:

Tetisol Career Hub: learning connected to employability.

## Production Notes

- Keep each product section under 25 seconds.
- Use screen recordings for real product credibility.
- Use short captions instead of long paragraphs on screen.
- Avoid showing implementation caveats until the technical foundation section.
- When discussing scaffolded work, frame it as future-ready architecture rather than completed production persistence.
